# 首版实服验收

环境：SwiftlyS2 >= 1.5.3、本次同步更新的 sws2-cs2menus（提供 sws2-cs2menus.custom-hud.v1 共享就绪回调），已挂载其编译后的 Panorama addon，core.jsonc 的 FollowCS2ServerGuidelines=false。安装后重启/换图，使探员资源预缓存。记录 CS2 构建号、SwiftlyS2 版本、armory 版本与服务端错误日志。

1. 一名玩家进入 T、一名进入 CT。使用 `!armory` 检查新版 HUD 的五个侧栏入口、右侧页面及第一项自动打开；翻页、进入分类、返回/关闭；搜索中英文。印花大分类的范围菜单应能到达所有条目，且不阻塞游戏。
2. AK-47、AWP、M4A1-S 和 USP-S 各选择皮肤，观察第一/第三人称和检视。先打掉几发子弹，再分别对手持枪械和收起的枪械换肤。检查更换后即时显示、弹匣和备弹数量、当前手持武器，以及开火和装填。另在买枪前选好皮肤，确认新买的枪继承选择。
3. 在 T 与 CT 各用 `!knife` 从队伍默认刀切换到爪子刀「自动化」，再选同刀型的原版饰面和另一款涂装。保持本次出生和当前队伍，检查手持刀具的第一人称外观是否立即更新。分别测试仅持刀、同时带枪、手持枪时换刀。切换至折刀「表面淬火」后检查拔刀、轻击、重击和检视动画。重生及下一回合应保持选择。若外观未变，持刀用 `!armorystatus` 记录服务端的模型、刀型和涂装编号。
4. 手套切换两种类型并调整 Float、Seed；重生、切换探员、切换 T/CT 后检查双手与第三人称。重置后重生，确认默认/库存手套恢复。
5. T、CT 各选对应探员，切换队伍并重生；检查模型、语音和无线电。热加载时选择未预缓存探员应提示下一张图生效，换图后再验证。
6. 选音乐盒，查看记分板；触发该玩家 MVP、击杀及回合事件，检查声音、MVP 计数、重连与换图后的选择。核弹爆炸后 MVP 的死亡视角播放仍需验证。
7. 对同一把枪的 0–4 五个槽位分别选印花，移除第 4 槽。对原版枪械和已选皮肤的枪械分别安装、更换和移除挂件，检查手持、检视和其他玩家视角。切换皮肤、重生、重新购买和重连后检查已保存的挂件。
8. 分别设置 Float=0、0.123456、1，Seed=0、661、1000。输入 NaN、Infinity、1.1、负 seed、seed=1001 应被拒绝。测试 Unicode 名称和过长名称。
9. 打开 StatTrak，设置 100 并击杀敌人；计数增加且模型数字可见。自杀、队伤、手雷击杀不应增加手中枪械计数；关闭后计数器消失。手套不能开启 StatTrak。
10. 玩家 A 丢枪给 B，B 有自己的选择/没有选择分别验证；两人同时更换饰品互不影响。玩家断线后另一人占据同一 slot，不得继承前者选择或触发前者延迟回调。
11. 连续修改几次后立刻重连/重启，最后的 Float、Seed、印花、探员和音乐盒选择应保留。`!armoryreset confirm` 后重连、重生及换图，确认偏好清空。
12. 热修改配置分别关闭类别，再关闭 Enabled。旧菜单不可继续修改关闭类别，存档不删除；重新开启后选择恢复。重载 menus 时，armory 的旧菜单关闭，重新开菜单应正常；将 menus 切到 classic 或移除 HUD 资源时，军械库应拒绝打开菜单并提示 HUD 未就绪，不显示旧菜单；资源恢复后重新打开正常。无 menus 时用直接设置命令。
13. 检查目录及存档权限错误日志。停服备份一个玩家存档，将副本改成错误 JSON 或越界数据；启动/重连应拒绝应用且保留错误文件，修复后重连可恢复。

本仓库未连接真实 CS2 服务器。以上为待维护者执行的验收步骤，不是已通过的测试记录。

新版 HUD 专项：检查印花、挂件、探员、音乐盒、Float、Seed、StatTrak 与重置都能从五个侧栏入口到达；选择饰品后“已装备”标记更新，导航栈不增长、返回保留父页。打开 admin 后直接输入 !armoryreset，军械库不能嵌入 admin 的导航栈。

共享合约兼容专项：保留服务器上 admin、mapmanager、rockthevote 的原有版本，完整更新 menus 与 armory 后重启整个 CS2 进程。确认不再出现 `IMenuService.get_IsCustomHudAvailable()` 的 MissingMethodException；挂载 addon 后菜单正常、HUD 状态可查询。重载 menus 后再次验证 armory 重新取得回调；将 menus 设置为 classic 后 armory 拒绝开菜单。离线 CI 已用旧版合约预加载覆盖二进制兼容性，真实服务器的加载顺序仍需执行本项验收。
